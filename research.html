We work across nanomagnetic, photonic and nanoelectronic substrates. The common question is how to make a physical system compute and learn using the physics it already has.

Nanomagnetic physics & networks

Artificial spin ice is a lattice of nanomagnets, each small enough to behave as a single macrospin. The array has a vast number of stable, reconfigurable microstates. We use these as physical neural networks.

We have developed ways to write arbitrary microstates, to read them out through their spin-wave spectra, and to use the resulting dynamics for reservoir computing and learning.

Reconfigurable magnonics

Spin waves carry information at GHz frequencies with low dissipation. In nanomagnet arrays their spectrum is set by the magnetic configuration, so rewriting the state reprograms the signal processing.

Current work couples magnonic systems to integrated photonics for optical readout, and links spin-torque oscillators through shared microwave lines.

Funded by EPSRC.

Neuromorphic photonics

A random network laser is a mesh of waveguides in a gain medium. Shaping the optical pump with a micromirror array changes which modes lase, giving a fast, high-dimensional optical system that can be trained.

We design these networks with graph theory, train them through digital twins, and build magneto-photonic hardware for low-energy machine vision. Our spin-out, Rayd Technologies, takes neuromorphic photonics towards products.

Funded by the ERC Starting Grant MORPHON and Innovate UK.

Physical learning

We build physical networks of nonlinear silicon devices whose response curves differ from one device to the next, and learn their nonlinear dynamics directly in hardware. These include Kolmogorov-Arnold networks, which put learnable nonlinear functions on the connections between neurons.

We study how device heterogeneity shapes what these networks can learn. Target applications include sensors that recalibrate as they drift and hardware that recovers from damage.

Funded by the EIC Pathfinder project KAN-DO-IT.
